# DAFAN AI AGENT (Android)

مشروع Android بسيط بواجهة عربية، يستخدم نموذج Qwen2.5-0.5B-Instruct عبر Transformers.js وONNX Runtime WebAssembly داخل Android WebView. لا يحتاج API key. يتطلب اتصالاً بالإنترنت لتنزيل ملفات النموذج أول مرة؛ بعد اكتمال التخزين المؤقت قد يعمل دون اتصال، حسب احتفاظ Android بملفات WebView المؤقتة.

## بناء APK من GitHub
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. شغّل workflow باسم **Build DAFAN AI AGENT APK**.
4. بعد النجاح افتح نتيجة التشغيل ونزّل Artifact باسم `DAFAN-AI-AGENT-debug-apk`.
5. فك ضغطه لتحصل على `app-debug.apk`.

## تخصيص عدد الوكلاء
في `app/src/main/assets/index.html` عدّل مصفوفة `AGENT_CONFIG`:
```js
const AGENT_CONFIG = [
  {name:"المساعد العام", instruction:"..."},
  {name:"فاحص المواقع", instruction:"..."},
  {name:"المحلل", instruction:"..."}
];
```
الوكلاء هنا أدوار مستقلة تتشارك نموذجاً واحداً لتقليل استهلاك الذاكرة، وليست نماذج منفصلة تعمل بالتوازي.

## حدود النسخة
- لا يوجد API أو مفتاح مدفوع.
- النموذج صغير (0.5B) وقد تكون إجاباته محدودة وبطيئة على أجهزة RAM 4GB.
- التنزيل الأول للنموذج يحتاج الإنترنت، وملفات النموذج ليست مضمنة في APK.
- فاحص المواقع يجلب HTML ويحلل النص الظاهر فقط؛ لا ينفذ JavaScript بالموقع ولا يفحص ثغرات أمنية ولا يضمن اكتشاف جميع المشكلات.
- هذه النسخة لا تنشئ صوراً أو تحول الصور فعلياً؛ تحويل الصور يحتاج نموذج توليد صور منفصل وكبير.
- لا تستخدم التطبيق لإدخال كلمات مرور أو بيانات حساسة.
